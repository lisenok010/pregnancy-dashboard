# Pregnancy Dashboard

Личный дашборд для отслеживания беременности — анализы, УЗИ, генетика, мониторинг АД и веса.

## Стек
React + Vite + Tailwind CSS + Recharts + Lucide Icons

## Локальный запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```

Деплой автоматический через GitHub Actions при push в `main`.
