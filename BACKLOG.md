# Бэклог дашборда беременности

## Известные проблемы

### 1. Категоризация серологии
Анализы на антитела (гепатит C, ВИЧ, сифилис) попадают в неправильные категории — "Моча" или "Другое".
**Причина:** в analysisTypes.js категории определяются по ключевым словам, но серология не учтена.
**Решение:** добавить категорию "Инфекции/Серология" с правилами для anti-HCV, anti-HIV, anti-Treponema и т.д.

### 2. Качественные отклонения не подсвечиваются
Дашборд помечает "вне нормы" только для числовых значений. Если значение текстовое
("в большом количестве", "положительный", "обнаружено"), и норма тоже текстовая
("в небольшом количестве", "отрицательный", "не обнаружено") — отклонение не ловится.
**Решение:** AI должен возвращать флаг `isAbnormal: true/false` для каждого показателя.
Дополнительно можно ловить звёздочку (*) которую лаба ставит в PDF возле значений вне нормы.

### 3. Десктопный адаптив
Сейчас layout жёстко мобильный (max-w-md = 448px). На десктопе много пустоты по бокам.
**Решение:** добавить `md:max-w-2xl` или 2-колоночный layout для md+ экранов.

## Идеи фич

- Шеринг с врачом через token-ссылку и QR
- Уведомления о пересдаче анализов
- Тренды по триместрам
- Экспорт всех анализов в PDF для врача
- Напоминания о УЗИ и скринингах по неделям
